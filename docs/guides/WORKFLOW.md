# Workflow Guide

Last updated: 2026-04-25

本文件说明 MealMate Web 的 Harness 工作流入口。

## 标准流程

1. 先读 `AGENTS.md` 和 `docs/HARNESS.md`，判断任务类型。
2. 按改动范围读取最小事实来源。
3. 多步骤改动更新 `docs/active/{requirement}/`。
4. 实现时遵守架构、前端、业务语义和组件协议边界。
5. 完成前运行匹配风险的验证命令。
6. 同步文档、测试和遗留项。

更完整的分层、落点和验收清单见 [docs/HARNESS.md](/home/yangyang/workspace/codes/Yggdrasil-Labs/mealmate-web/docs/HARNESS.md)。
