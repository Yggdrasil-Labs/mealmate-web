# MealMate 业务文档

本目录用于沉淀 `mealmate-web` 所依赖的业务背景、产品边界与 Web 端实施约束，避免业务信息只停留在外部笔记中。

## 文档分层

- `mealmate-domain-context.md`：沉淀业务本质、核心闭环、领域划分与统一语言。
- `mealmate-web-scope.md`：沉淀 Web 仓库的职责边界、页面范围、交互边界与阶段性实施重点。

## 使用约定

- 业务抽象优先写在本目录，不混入组件协议文档。
- 仓库实现细节、通用组件协议继续维护在 `docs/components/`。
- 新增业务能力时，优先同步更新本目录中的术语、页面范围与边界约束。
